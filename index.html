Cardiovascular Medical Device Recalls

openFDA API Python Chart.js Root Cause Analysis

Pulled live FDA recall data for cardiovascular medical devices and recoded 15 raw root-cause categories into four analyst-defined buckets — the same triage work used in a CAPA program.

Key finding: Manufacturing/Process issues (37.3%) edge out Design issues (32.8%) as the top recall driver — the opposite of the common assumption that recalls are mostly design flaws.
