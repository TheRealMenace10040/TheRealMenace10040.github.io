Cardiovascular Medical Device Recalls

openFDA API Python Chart.js Root Cause Analysis

Pulled live FDA recall data for cardiovascular medical devices and recoded 15 raw root-cause categories into four analyst-defined buckets — the same triage work used in a CAPA program.

Key finding: Manufacturing/Process issues (37.3%) edge out Design issues (32.8%) as the top recall driver — the opposite of the common assumption that recalls are mostly design flaws.

Lab Supply & Vendor Performance Tracker

Excel VBA COUNTIFS / SUMIFS Purchasing

An Excel tool for the time-sensitive supplies a QC lab runs on. It scores 8 vendors on on-time delivery and lead time across 320 purchase orders, flags expiring lots, and calculates reorder points. VBA macros import new POs, export a dated reorder list, and refresh the dashboard. Synthetic data.

Key finding: One calibration vendor delivers on time only 75% of the time and gets flagged "At risk", while overall on-time delivery is 89.7%. Six items sit below their reorder point.

Environmental Monitoring QC Trend Report

Python SQL Excel VBA

A small pipeline for cleanroom EM results. Python generates 3,600 results, SQL (views, CTEs, self-joins) finds excursion trends and repeat excursions, and a formula-driven Excel report with a VBA macro builds the weekly summary and exports it to PDF. Synthetic data; limits are illustrative.

Key finding: The excursion rate runs 2-5% most months but jumps to 8.0% in July. One ISO 7 room nearly tripled its rate in the last 30 days against its 90-day baseline.
