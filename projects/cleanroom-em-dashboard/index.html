6.0Basis of limits

All records are simulated for a portfolio demonstration and contain no proprietary site data. Particulates use ISO 14644-1 class limits per m³ at 0.5 µm and 5.0 µm. Microbial action levels are illustrative and modelled on EU GMP Annex 1 grade levels, with alert set at 60% of action. Differential pressure uses a floor: below 0.030 in. WC is an Alert, below 0.020 in. WC is an Action. Production rooms run AM, AP, PER, WS and DP monthly. ISO 8 gowning rooms run AM, AP and DP quarterly. AM, AP, PER and WS results average 12 to 40 samples; DP averages 1 to 4 entrance readings.
